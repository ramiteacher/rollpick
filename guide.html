구슬 추첨기 사용법 RollPick 가이드

이름을 쉼표나 줄바꿈으로 넣고 시작을 누르면 끝입니다. 아래는 입력 규칙, 당첨 방식, 진행 중 조작, 결과 활용까지의 전체 안내입니다.

기준 버전: RollPick 1.0.0 (2026-09-18)

1. 이름 입력 규칙

입력의미예시
이름구슬 1개홍길동
이름*숫자같은 이름의 구슬을 숫자만큼 (응모 횟수)홍길동*3 → 구슬 3개
이름/숫자무게. 클수록 스킬 발동 확률이 높고 쿨타임이 짧음홍길동/5
이름*3/5응모 횟수와 무게를 함께홍길동*3/5
  • 구분자는 쉼표(,)와 줄바꿈 모두 됩니다. 앞뒤 공백은 무시됩니다.
  • 입력창을 벗어나면 중복된 이름이 자동으로 이름*개수 형태로 합쳐집니다.
  • 구슬은 최대 500개까지 넣을 수 있습니다. 더 많으면 물리 연산이 느려져 시작이 막힙니다.
  • 입력한 이름은 이 브라우저의 로컬 저장소에만 저장됩니다. 다음에 열면 그대로 남아 있습니다.

2. 당첨 방식

버튼당첨자이럴 때
1등가장 먼저 골인한 구슬경품 1명
꼴찌마지막까지 남은 구슬벌칙, 계산 담당
등수 입력입력한 등수의 구슬 (예: 7등)특정 순번에 상품
여러 명입력한 범위의 구슬 전부 (예: 1~5등)발표 순서, 조 편성

범위나 등수가 구슬 수보다 크면 자동으로 구슬 수에 맞춰 잘립니다.

3. 설정

  • 맵: 운명의 수레바퀴, 버블팝, 욕망의 항아리, 밤을 달리다 4종. 맵을 바꾸면 구슬이 새 맵의 출발 위치로 다시 배치됩니다.
  • 스킬: 켜면 구슬이 쿨타임마다 확률적으로 순간 가속합니다. 끄면 순수 물리 낙하만으로 결정됩니다.
  • 녹화: 켜면 시작부터 결과까지 화면이 녹화되고, 끝나면 영상 파일이 자동 다운로드됩니다. 브라우저의 MediaRecorder 지원이 필요합니다.
  • 테마·언어: 상단 버튼으로 다크/라이트, 한국어·English·日本語를 바꿀 수 있고 선택은 저장됩니다.

4. 진행 중 조작

조작동작
화면 가운데 길게 누르기누르는 동안 2배속
왼쪽 미니맵 드래그보고 싶은 위치로 카메라 이동
오른쪽 순위 목록 휠순위 목록 스크롤
오른쪽 순위 목록 더블클릭순위·이름·당첨 여부를 표(TSV)로 복사
중단 버튼 / Esc추첨을 멈추고 처음 상태로
Ctrl + Enter시작

구슬이 5초 이상 한자리에 멈춰 있으면 자동으로 살짝 튕겨 다시 움직입니다. 당첨 구슬이 골인 직전이면 슬로모션으로 전환됩니다.

5. 결과 활용

  • 복사: 당첨자 목록을 "#1 이름" 형식의 텍스트로 복사합니다.
  • 공유: 모바일에서는 공유 시트가 열리고, PC에서는 텍스트가 복사됩니다.
  • 전체 순위: 당첨자뿐 아니라 모든 구슬의 골인 순서를 볼 수 있습니다.
  • 기록: 상단 시계 아이콘에서 최근 30번의 추첨 결과(시간·맵·당첨자)를 다시 볼 수 있습니다.
  • 링크 복사: 현재 명단이 담긴 주소(?names=이름1,이름2)를 복사해 다른 사람에게 보낼 수 있습니다.

자주 묻는 질문

같은 사람을 여러 번 응모시키려면 어떻게 하나요?
이름 뒤에 *숫자를 붙입니다. 예를 들어 홍길동*3은 홍길동 구슬을 3개 넣어 당첨 확률을 3배로 만듭니다.
무게(/숫자)는 무엇을 바꾸나요?
무게는 구슬의 스킬(순간 가속) 발동 확률과 쿨타임에만 영향을 주며, 스킬을 끄면 무게 차이는 결과에 영향을 주지 않습니다.
추첨 결과를 표로 복사할 수 있나요?
네. 추첨 중이나 종료 후 오른쪽 순위 목록을 더블클릭하면 순위·이름·당첨 여부가 탭으로 구분된 표(TSV)로 클립보드에 복사됩니다.
