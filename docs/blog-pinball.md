# 핀볼 뽑기 무료로 하는 법, 수업 발표자 뽑을 때 이렇게 씁니다 (RollPick)

수업 시간에 발표자 한 명 뽑는 게 은근히 일이었습니다. 번호 뽑기 앱을 쓰면 "선생님이 미리 정한 거 아니냐"는 소리가 꼭 나오고, 사다리 타기는 인원이 많으면 화면이 복잡해지고요. 그래서 학생들이 결과가 나오는 과정을 직접 보는 방식이 필요했고, 결국 핀볼 뽑기로 정착했습니다.

핀볼 뽑기는 이름이 적힌 구슬을 장애물이 있는 판에 떨어뜨려서, 먼저 도착한 구슬을 당첨자로 정하는 방식입니다. 구슬이 튕기고 부딪히는 게 다 보이니까 누구도 결과에 토를 달지 않더라고요.

제가 쓰는 건 RollPick이라는 무료 사이트입니다. 설치도 회원가입도 없고 브라우저에서 바로 열립니다.

👉 https://ramiteacher.github.io/rollpick/pinball.html

(여기에 추첨 화면 스크린샷 1장)

## 쓰는 방법은 3단계입니다

1. 이름을 쉼표나 줄바꿈으로 넣습니다. 출석부에서 복사해 붙여넣으면 끝이에요.
2. 당첨 방식을 고릅니다. 1등, 마지막, 특정 등수, 여러 명(예: 1~5등) 중 하나.
3. 시작을 누르면 구슬이 떨어지고, 결과 창에 당첨자가 뜹니다.

시간이 없을 땐 화면 가운데를 누르고 있으면 2배속으로 넘어갑니다. 저는 발표 순서 정할 때 "여러 명 1~5"로 두고 한 번에 다섯 명을 뽑습니다. 골인 순서가 곧 발표 순서라 따로 정리할 게 없어요.

(여기에 결과 창 스크린샷 1장)

## 제가 자주 쓰는 설정

| 상황 | 설정 |
|---|---|
| 발표자 1명 | 당첨 = 1등 |
| 발표 순서 5명 | 당첨 = 여러 명, 1~5 |
| 청소 당번 | 당첨 = 마지막 |
| 과제 낸 학생 확률 2배 | 이름 뒤에 `*2` |

이름 뒤에 `*3`을 붙이면 그 이름의 구슬이 3개 들어갑니다. 응모 횟수가 다른 이벤트 추첨에도 그대로 쓸 수 있어요.

## 학생 이름을 넣어도 괜찮은 이유

입력한 이름은 서버로 가지 않고 내 브라우저에만 저장됩니다. 결과도 서버가 정하는 게 아니라 브라우저 안의 물리 엔진(Box2D)이 계산하고요. 개인정보가 걱정되면 이름 대신 번호(1번, 2번…)만 넣어도 됩니다.

반마다 명단이 다르면 "링크 복사" 버튼으로 명단이 담긴 주소를 만들어 즐겨찾기에 저장해 두세요. 다음 수업엔 그 주소만 열면 바로 시작됩니다.

## 이런 분께 맞습니다

- 발표자·조 편성을 학생들이 납득하게 정하고 싶은 선생님
- 시청자 이벤트 당첨자를 뽑으면서 녹화 증빙을 남겨야 하는 방송 하시는 분 (녹화 옵션 켜면 영상이 자동 저장됩니다)
- 회식 자리에서 계산 담당을 정해야 하는 분 (마지막 모드)
