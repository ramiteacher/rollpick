방송·이벤트 당첨자 추첨 녹화되는 시청자 뽑기

응모자 명단을 넣고 시작을 누르면 시청자가 보는 앞에서 구슬이 떨어지며 당첨자가 정해집니다. 응모 횟수는 닉네임*횟수로 반영하고, 녹화를 켜면 추첨 영상이 자동으로 저장되어 증빙으로 남습니다.

기준일: 2026-09-18 · 무료 · 설치 없음 · 방송·상업 이벤트 사용 허용(MIT)

응모 횟수 예시로 바로 뽑아보기 →

추첨 진행 순서

  1. 명단 정리: 채팅·댓글·구글폼에서 모은 닉네임을 한 줄에 하나씩 붙여넣습니다. 여러 번 응모한 사람은 닉네임*횟수로 씁니다. 같은 닉네임을 여러 줄 넣어도 자동으로 합쳐집니다.
  2. 당첨 인원 설정: 1명이면 "1등", 여러 명이면 "여러 명"에서 1 ~ N을 넣습니다.
  3. 녹화 켜기: 설정의 녹화 스위치를 켭니다. 브라우저가 화면을 녹화해 종료 시 파일을 저장합니다.
  4. 시작: 시청자가 볼 수 있게 전체 화면으로 두고 시작합니다. 길면 화면 가운데를 눌러 2배속으로 넘길 수 있습니다.
  5. 결과 공지: 결과 창의 복사 버튼으로 당첨자 목록을 채팅·공지에 붙여넣습니다.

방송 화면 구성 팁

항목권장
맵응모 100명 이상이면 진행 시간이 긴 "밤을 달리다", 소규모는 "운명의 수레바퀴"
테마어두운 방송 레이아웃엔 다크, 밝은 화면엔 라이트
스킬순수 확률로 보여주고 싶으면 끄기. 연출을 원하면 켜기
캡처OBS 등에서 브라우저 창을 소스로 추가. 전체 화면 버튼으로 UI 여백 제거
공정성 안내"출발 순서 무작위, 결과는 물리 엔진 계산"을 사전 고지하면 문의가 줄어듭니다

오프라인 이벤트에서

  • 참가자 번호표(1번~N번)로 명단을 만들면 개인정보를 화면에 띄우지 않아도 됩니다.
  • 경품이 여러 개면 "여러 명" 모드로 1등부터 순서대로 뽑아 순위별 경품을 배정합니다.
  • 기록 버튼에 최근 30회 결과가 남아 있어 행사 후 정리에 쓸 수 있습니다.

자주 묻는 질문

방송에 써도 되나요? 저작권 문제는 없나요?
네. RollPick은 MIT 라이선스 오픈소스이며 방송, 영상, 상업 이벤트를 포함해 어떤 용도로든 무료로 사용할 수 있습니다.
응모 횟수가 다른 참가자는 어떻게 넣나요?
이름 뒤에 *횟수를 붙입니다. 예를 들어 닉네임*5는 구슬 5개가 들어가 확률이 5배가 됩니다. 중복 입력하면 자동으로 합쳐집니다.
추첨 영상은 어떻게 남기나요?
설정에서 녹화를 켜고 시작하면 추첨이 끝났을 때 영상 파일이 자동으로 다운로드됩니다. 방송 송출 프로그램의 화면 녹화와 함께 쓰면 이중으로 증빙이 남습니다.
