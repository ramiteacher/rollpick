      RollPick 사용법

      RollPick은 물리 엔진 위에서 구슬을 굴려 당첨자를 뽑는 랜덤 추첨기입니다. 결과는 미리 정해지지 않으며 구슬의 충돌과 낙하 과정으로 자연스럽게 결정됩니다.

      1. 이름을 쉼표(,)나 줄바꿈으로 구분해 입력합니다.
      2. 맵과 당첨 방식(1등 / 꼴찌 / 특정 등수 / 여러 명)을 고릅니다.
      3. 시작 버튼을 누르면 구슬이 떨어지며 추첨이 진행됩니다.
      4. 결과 창에서 당첨자를 확인하고 복사·공유하거나 다시 뽑습니다.

      이름 입력 규칙

      • 이름*3 : 같은 이름의 구슬을 3개 넣습니다. (응모 횟수)
      • 이름/5 : 무게를 5로 둡니다. 무거운 구슬일수록 스킬 발동 확률이 높습니다.
      • 중복된 이름은 입력창을 벗어날 때 자동으로 합쳐집니다.

      팁

      • 추첨 중 화면 가운데를 누르고 있으면 2배속으로 진행됩니다.
      • 왼쪽 미니맵을 드래그하면 원하는 위치를 볼 수 있습니다.
      • 오른쪽 순위 목록은 마우스 휠로 스크롤하고, 더블클릭하면 표(TSV)로 복사됩니다.
      • 녹화를 켜면 추첨 영상이 자동으로 다운로드됩니다. (브라우저 지원 필요)
      • Ctrl + Enter 로 바로 시작할 수 있습니다.
      • 주소 뒤에 ?names=이름1,이름2 를 붙이면 명단이 채워진 링크를 공유할 수 있습니다.

      자주 묻는 질문

      결과가 공정한가요?
      구슬의 초기 배치는 무작위로 섞이고, 이후 경로는 물리 시뮬레이션으로만 결정됩니다. 서버와 통신하지 않으며 모든 계산은 브라우저 안에서 이뤄집니다.
      무료로 써도 되나요?
      네. 수업, 방송, 이벤트, 회식 등 어디서든 자유롭게 사용할 수 있습니다.
      입력한 이름은 어디에 저장되나요?
      브라우저의 로컬 저장소에만 저장되며 외부로 전송되지 않습니다.
      구슬이 멈춰 있으면 어떻게 되나요?
      일정 시간 이상 멈춘 구슬은 자동으로 살짝 튕겨 다시 움직입니다.
